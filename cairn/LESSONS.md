# Lessons

<!-- Append-only, capped at 50 lines (D-015). Durable repo lessons — build quirks, testing tricks — captured
     at milestone end, surfaced at plan time. A *choice* is a D-entry, not a lesson. -->

- 2026-08-24 (M054): `jsonlite::fromJSON(simplifyVector = TRUE)`'s other two simplifications each defeat a shape guard on a hand-editable format — an array of objects becomes a *data frame*, a list WITH names that walks past a "top level must be a named object" check, and a nested array becomes a matrix that `as.integer()` silently flattens, while a ragged one stays a list that `as.integer()` refuses with a bare `simpleError` naming neither field nor file. Parse a flat object of scalars and number arrays with `simplifyDataFrame = FALSE, simplifyMatrix = FALSE`, and coerce every number field through one helper raising the format's classed condition.
- 2026-07-16 (M020): byte-locked repo artifacts need `.gitattributes` `-text` — Windows `actions/checkout` CRLF-converts anything git sniffs as text (.txt/.qsf), silently mutating committed bytes before tests see them.
- 2026-07-16 (M020, extended M053, M058, M059): DOCX and REDCap zip builds are not byte-deterministic (member mtimes, date stamps) — only flat text outputs can be md5-compared across rebuilds; content comparisons parse inside the container with tag boundaries anchored. WordprocessingML nests tags whose names prefix each other, so splitting on bare `<w:tr` also matches `<w:trPr`, shredding a 13-row form into 39 empty rows; require `>` or whitespace after the name (`/<w:tr[ >]/`) and sanity-check the count. The same blindness defeats a *scan*: grepping tracked files as raw bytes is inert against compressed containers (`data/*.rda`, `.docx` scan as noise and report clean) — opening each format in its own terms took a rename sweep from 2 hits to 9. Two orderings of the same names can disagree: `dplyr::arrange()` sorts in the C locale, base `order()` in the running locale's. The sweep's own build record is a shipped surface — `hitop_artifacts$changes` named the retired spelling after every keying table was clean.
- 2026-07-17 (M021): pkgdown download-page vignettes render `hitop::hitop_artifacts` from the *installed* package, and `pkgdown/extra.css` copies to `docs/` only on `init_site()`/`build_site()` — after editing data or CSS, `devtools::install()` + a full/`init_site()` build is needed or `build_article()` shows stale content.
- 2026-07-30 (M025, extended M058): `on.exit()` at the top level of an Rscript fires at the end of its own top-level statement, not at script end — a script that swaps a tracked file out and back leaves the mutation behind; put the swap and its restore inside a function. The same trap leaks resources: a top-level `git worktree add` whose removal never fired left 15 stale registrations across a milestone's runs, and its `dir.exists()` fallback could never fire either, since `tempdir()` differs every session. A cleanup guarded on a path that changes per run is not a cleanup.
- 2026-07-30 (M026): `usethis::use_data()` rewrites every dataset its script saves, so an unchanged one still shows as modified through non-deterministic recompression — compare the loaded object against the ref (`load()` from `git show`) and `git checkout` the file back, or the diff claims changes that aren't there.
- 2026-07-30 (M026): the generated paper forms carry "Reverse-scored items are indicated with (R)." in their own instruction text, so a test searching a DOCX for a bare `"(R)"` matches every form ever built and asserts nothing — anchor the pattern to a digit (`[0-9]\(R\)`).
- 2026-07-30 (M027): a nearest-row lookup built on `outer(x, table, "-")` breaks on non-finite or very large `x` — every distance is `Inf` (or collapses to one float past ~1e15), so every row ties and the tie-break decides. Clamp `x` into the table's range before measuring distances.
- 2026-07-31 (M029): converting a `cli_alert_*` report to `cli::cli_warn()` turns console noise testthat ignores into a warning it fails on — every existing test that merely *calls* the function needs sweeping, not just the ones asserting on the message.
- 2026-07-31 (M029): `local_mocked_bindings()` cannot rebind lazy-loaded package data (`pid_norms`), so a branch gated on the data's contents is reached by mocking the predicate that reads it (`norm_covers()`), never the data itself.
- 2026-07-31 (M030, absorbing M027 2026-08-21): a cli plural marker takes its quantity from the LAST value interpolated before it in the same string. With none, `{?s}` aborts at runtime with "Cannot pluralize without a quantity" — and only when that message is actually emitted. With `{cli::qty(n)}` at the head, an intervening `{substitution}` cancels it and the marker silently renders singular. Put `qty()` immediately before the `{?a/b}` it governs.
- 2026-07-31 (M031): a characterization harness that feeds only valid arguments measures returned values and is structurally blind to which inputs are *accepted* — converting argument checks needs a separate differential accept/reject probe (`git archive` the base ref to a temp dir, run both, compare verdicts only), or a narrowed argument silently ships.
- 2026-07-31 (M032, extended M039, M043, M060, M065): testthat expectation traps. `expect_setequal()` and `expect_length()` accept no `info`/`label`, so neither can name a failing loop iteration. `expect_no_warning(object, message = )` takes `message` as a REGEXP selecting which warnings count, so it PASSES even when a warning is raised; `expect_no_error()` does the same. `expect_no_warning(expect_error(expr, class = ))` never sees a warning raised BEFORE the error, the inner expectation having captured the call, so such a guard is vacuous (M060 shipped one; a planted reorder left it green). Recast as `expect_equal(..., info = ...)`, capture with `withCallingHandlers`, and prove any ordering guard by planting the reorder. A value that fails an expectation and is then USED aborts the whole `test_that()` block, hiding every later assertion — `rlang::call_name(NULL)` errors rather than failing, so a `conditionCall()` test whose `call` goes NULL takes the block with it; substitute a placeholder (`quote(no_call())`). In a loop the same shape truncates the RED run while leaving the green one whole, corrupting discrimination evidence: `expect_length(said, 1L)` records a failure but does not stop, then `msgs[[said]]` throws on `integer(0)`, so reverting the feature reported one generator of three. Guard with `next` after any such expectation.
- 2026-07-31 (M031): `rlang::arg_match()` is not a drop-in for either `match.arg()` or an `x %in% choices` test — it requires an exact match (no partial matching) *and* a character vector, so it rejects a factor that `%in%` accepted.
- 2026-07-31 (M033): `pid_scales[["BF"]]` carries a `camelCase` column too (its five domains and `total`), so a branch guarded on `s %in% pid_scales[[v]]$camelCase` matches BF as well as the facet versions and silently shadows any BF branch below it — key such a test on `v %in% c("FULL", "SF")` instead.
- 2026-07-31 (M033): a cell-by-cell diff written `which(a != b)` reports nothing wherever either side is `NA`, so a CSV cell that fails to parse (a letter `O` for a zero) passes as matching — compare NA-aware (`is.na(a) | is.na(b) | a != b`) and guard the parsed side with `!anyNA()`.
- 2026-07-31 (M034, corrected M035): both mutation harnesses (`data-raw/mutate_norms_check.R`, `mutate_norms_book_check.R`) swap the tracked `data/pid_norms.rda` in place while they run, so any concurrent reader (a review subagent, a parallel `devtools::test()`) sees a corrupted dataset and reports phantom mismatches; run either against a `git archive` export of HEAD when anything else may be reading the checkout.
- 2026-07-31 (M034): to check a test file's fixture tables from outside, evaluate only its top-level `<-` calls (`for (e in parse(f)) if (is.call(e) && identical(as.character(e[[1]]), "<-")) eval(e, env)`) — regex-scraping `list(...)` literals silently misses any table built from vectors, as `facet_spot`'s 50 rows are.
- 2026-07-31 (M036): a test written to discriminate a derived default from a hardcoded constant must use an input where the two actually differ — a 3-option legend table separates neither, since `seq(1, 3, by = 3)` and `seq(1, 3, by = 4)` both yield one start, so the test passed against the very mutation its comment named; pick an input above the constant and re-run the mutation to confirm red.
- 2026-07-31 (M036): Word cannot be driven from a session on this machine — its AppleScript `save as` errors -1708 and `osascript` holds no accessibility grant, so no DOCX→PDF export and no window capture; `qlmanage -t -s 1600 -o <dir> <file>.docx` renders a page image for a visual layout check, but it is QuickLook's line breaking, not Word's, and any wrap claim must say so.
- 2026-08-01 (M037): a differential probe whose recorder returns the condition whenever one is signalled silently drops the returned value for any call that *warns and still returns* (the misordered-`items` case), so the value comparison it claims never happens for that cell — record value and condition together, not one or the other.
- 2026-07-31 (M035, extended M058): a name-keyed diff cannot check a value it uses *as* the key — `pid_norms`'s validity scales key on `raw`, so a changed raw score surfaces as a paired extra-row + missing-row, not a value difference; key on the index the source prints. The dual blindness is that matching rows by key ABSORBS any permutation, so a check reporting one expected row move fired identically on a planted two-scale swap. Assert the untouched rows' relative order separately, against a sort recomputed from the base names, not read off the output under test.
- 2026-08-01 (M038): pinning a discrete scale's limits (`scale_y_discrete(limits =)`) overrides facet_wrap/facet_grid's per-panel scale training, silently cancelling `scales = "free_y"` so every panel draws every level — pin only on an unfacetted plot, and assert per-panel axis content (`ggplot_build(p)$layout$panel_scales_y[[i]]$get_limits()`) rather than the facet spec.
- 2026-08-01 (M038): `coord_flip()` applies a facet's free scale *before* the flip, so `scales = "free_y"` frees the post-flip value axis rather than the scale-name axis — map the axes as they are drawn instead of building vertically and flipping.
- 2026-08-01 (M038): a ggplot2 discrete scale trained across layers places a value missing from an earlier layer *last*, not at its factor-level position, so a layer deliberately omitting one level (a profile line skipping a total) silently reorders the axis; assert the drawn order from built coordinates, which run opposite to factor level order.
- 2026-08-05 (M039): a ggplot2 rendering offset (`vjust`/`hjust`) is an absolute distance, while room reserved for it on a scale is in data units whose physical size shrinks with the panel — so no `expansion()` reservation is device-independent, and a fix verified at one figure size can clip at a smaller one. Offset into the axis with the most room, verify across figure sizes, and state the promise as a figure-size floor.
- 2026-08-05 (M039): a layer's `$position` cannot show whether a data-space nudge was applied — ggplot2 gives `geom_label()` a `PositionNudge` whose `$x` is `NULL` with or without `nudge_x`, so `expect_null(layer$position$x)` passes on the very mutation it claims to catch; assert instead that the label layer's built `x` equals the point layer's.
- 2026-08-05 (M039): `rmarkdown::html_vignette` is self-contained, so it base64-embeds figures and deletes the `_files` directory — a render leaves no figure files on disk to inspect unless it passes `output_options = list(self_contained = FALSE)`, and any stale `_files` contents must be cleared first or they inflate the count.
- 2026-08-01 (M038): a Suggests version floor is not enforced when a package is merely loaded, so declaring one in DESCRIPTION alone still lets an old version fail on an unknown argument — pass the same version to the `rlang::is_installed()` guard and hold the two statements of it in step with a test.
- 2026-08-13 (M040): `testthat::test_file(reporter = "silent")` records a thrown error in the result's `error` column, not `failed` — a mutation that makes the code under test abort outright reads as "0 failures" if only `failed` is summed, which silently inverts a mutation check's verdict. Sum `failed > 0 | error`.
- 2026-08-13 (M040): ggplot2 4.x plot objects are S7, so their properties ARE attributes — `attr(p, "data")` returns the internal data frame just as `p$data` does. Any check that means to stop code reading a plot's internals has to cover `attr()` too, not only `$`/`[[`.
- 2026-08-19 (M042): GitHub serves repo files by extension sniff — `.qsf`/`.txt` come back `text/plain` with no `Content-Disposition` while `.docx`/`.zip` get `application/octet-stream`; no URL variant changes it and `download` is ignored cross-origin, so the fix is same-origin hosting — `pkgdown/assets/<dir>/` copies to the site root, reached from an article as `../<dir>/<file>` (a root-relative `/<dir>/` 404s on a project page).
- 2026-08-21 (M043, extended M054, M057): an rlang `call =` argument used to blame the right function must default to `rlang::current_env()`, not `caller_env()` — a default is evaluated in the function's OWN frame, so `caller_env()` gives the caller's and a direct top-level call produces an error with no call. This governs a function's OWN `call =`, not a helper's: a helper declaring `caller_env()` has it evaluated inside the HELPER, so it already blames the right frame (`R/util.R`'s `cli_assert()` is correct). Even so it aborts with NO call when invoked inside another function's argument list — `tibble::tibble(Brief = scale_definitions(...))` forces the promise in `tibble()`'s frame — so resolve into a local first and check with `conditionCall()`.
- 2026-08-21 (M043): adding an argument can break callers with no rename in sight — `module` made the abbreviation `m = ` ambiguous with the pre-existing `missing = ` in `score_hitopsr()`, which now errors where it worked. R CMD check does not flag it and no deprecation shim can cover it; check new argument names against the partial matches of existing ones.
- 2026-08-22 (M045, extended M049-M053): R code under WebAssembly cannot shell out — `utils::zip()` uses `system2()` and aborts under Emscripten, where {zip}'s in-C implementation works (and off PATH anywhere). webR needs no COOP/COEP headers (plain GitHub Pages suffices) but requests from a Web Worker, invisible to the network panel. To review what it builds, patch `URL.createObjectURL` to keep the blob and return early from the anchor's `click`, then read it with `blob.text()` or `DecompressionStream('deflate-raw')`. To check which hosts it reaches, serve a copy under an enforced `Content-Security-Policy` and count `securitypolicyviolation` events, proving it binds by dropping one host; `jmgirard.r-universe.dev` 302s to `r2.ropensci.org`, which a host list must also name. Keyboard walk: injected keys arrive with an empty `code`, which Chrome requires before default activation, so Tab to each control and activate with `.click()` after confirming no key handler; Tab moves focus only once the document has real focus, so open with a mouse click clear of any link; `blur()` does not reset the tab position. A containment check measures against the container's *scroll* extent, not its viewport rect.
- 2026-08-22 (M046, extended M041, M067): an oracle that inverts the map under test asserts nothing — `item_order[match(v, item_order)] == v` is an identity for ANY order, and passed both a wrong order and a mutated generator; read the expected side OFF the artifact. A prose guard that CUTS the passage it asserts over is the same trap: `regexpr("\\section", rd)` matched nothing, the -1 widened the cut to the whole file, and the anchor held a phrase it asserted — assert BOTH boundaries were found, and anchor on the full distinctive shape (`order(` also matched an unrelated sort in the section; `collected[order(` did not). A plant scoring GREEN may be the wrong plant: Rd rewraps roxygen prose, so a literal replace misses the phrase — squash whitespace, then re-plant against the wrapped text.
- 2026-08-22 (M047): two traps when an R script shells out to git. `git check-attr` reports `unspecified`, not `auto`, for a path no `.gitattributes` rule covers, so a check comparing against `"auto"` finds zero convertible files and passes vacuously — treat `unspecified` as its own violation, since behavior falls back to `core.autocrlf`. And neither `pipe()` nor `system2(stdout = <file>)` keeps a filename away from a shell, so a path holding an apostrophe reads as zero bytes and scores clean: pass paths on stdin (`git cat-file --batch`) and check `attr(out, "status")` — R does not raise on a non-zero exit.
- 2026-08-24 (M055, extended M061, M062): two ways a path check passes on a path that writes nothing. `writeLines(x, con = "")` opens an ANONYMOUS connection and discards the write, so a guard testing only `is.character(p) && length(p) == 1L` succeeds having written nothing; require `nzchar()`. `normalizePath(p, mustWork = FALSE)` returns a non-existent path unchanged, so `dir/./f` and `dir/f` compare unequal; normalize `dirname(p)` and rejoin `basename(p)`. `data.frame()` is not a length guard — it aborts only when neither column length divides the other, so `data.frame(Scale = c("a","b"), nItems = 1:4)` returns four rows in silence. The same shape appears as an over-broad *exemption*: a control held outside a bulk disable is outside every disable, including the window where it must be off — scope an exemption to its motivating condition.
- 2026-08-25 (M056, extended M057, M062, M063, M064): the browser pane's click injection takes SCREENSHOT coordinates, not CSS px — at a 900x1000 viewport in an 800x889 frame a `ref` click lands ~11% low; compute `css * (shotW / innerWidth)` from a fresh screenshot, or `form_input` by ref. A `ref` click can also resolve to the viewport's centre on a scroll that never happens, landing every click in one dead band. Never take a reported coordinate as evidence a click landed — read back the state it changed, or actuate through the page's own handlers. A hidden pane stops dispatching clicks and `tabs_select` does not revive it — open a new tab; it also caches a served `index.html` across `navigate`. Escape does not test a tooltip's dismiss from a `type="search"` box, which Chrome clears first. `javascript_tool` times out at 45s while the PAGE keeps running what it started, so a retry double-drives it — poll in short calls, or run detached into a `window` variable and reload first. Probe a module script by serving a copy with one constant altered and a `window.__probe` hook appended inside the module; force a branch guarding a never-settling call by racing it against a promise the console can reject, the page first put in the state the branch must change.
- 2026-08-30 (M068): a printed table disagreeing with the package's keying can be the package's own error — one unsourced `hitopbr_items` cell explained both of Table 1's disagreeing `# Items` rows. Tabulate printed counts against the keying table first.

- 2026-09-01 (M077): a rename sweep that greps literal spellings misses names built at run time — `paste0("hsr_", 1:405)` in a maintainer-run `data-raw/` script that neither `check()` nor the grep reaches; grep the bare stem too, in every directory, and read each hit.
- 2026-09-01 (M078): a merge-base reliability differential runs ~40 min per side with a real `calc_omega()` (full HiTOP-SR: 76 lavaan CFAs per flag setting) — run both sides detached to `.rds`, never a foreground wait; tests needing only the columns mock it via `local_mocked_bindings()`.
