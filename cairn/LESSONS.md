- 2026-07-16 (M019, corrected 2026-08-19): the undocumented Qualtrics `GET /survey-definitions/{id}?format=qsf` endpoint returns a QSF that Qualtrics' own importer REJECTS — it encodes absent values as `{}` where a UI export writes `null`; normalize before committing (`normalize_qsf_nulls()` in `devel/qualtrics_hitophsum.R`). Validate by shape (SurveyEntry + SurveyElements) and never re-serialize through jsonlite (round-trips aren't byte-faithful).
- 2026-07-16 (M019): Qualtrics QSF exports serialize a dense zero-based choice map (values 0..n) as a JSON *array*, dropping the keys — recover them positionally from ChoiceOrder when parsing.
- 2026-07-16 (M020): byte-locked repo artifacts need `.gitattributes` `-text` — Windows `actions/checkout` CRLF-converts anything git sniffs as text (.txt/.qsf), silently mutating committed bytes before tests see them.
- 2026-07-16 (M020): DOCX and REDCap zip builds are not byte-deterministic (zip member mtimes, date stamps) — only flat text outputs can be md5-compared across rebuilds; content comparisons must parse inside the container.
- 2026-07-17 (M021): HTML emitted from a knitr chunk via `cat()`/`results='asis'` is still parsed as markdown by pandoc — `_1.0_` became emphasis. Wrap generated HTML in a ```` ```{=html} ```` raw fence so it passes through verbatim.
- 2026-07-17 (M021): pkgdown download-page vignettes render `hitop::hitop_artifacts` from the *installed* package, and `pkgdown/extra.css` copies to `docs/` only on `init_site()`/`build_site()` — after editing data or CSS, `devtools::install()` + a full/`init_site()` build is needed or `build_article()` shows stale content.
- 2026-07-17 (M022): `pkgdown::build_article("name")` (singular) errors "Can't find article" for a newly added `.Rmd` until the article index is rebuilt — use `build_articles()` (plural), or `init_site()`/`build_site()`, after adding a new article.
- 2026-07-30 (M025): `on.exit()` at the top level of an Rscript fires at the end of its own top-level statement, not at script end — a script that swaps a tracked file out and back leaves the mutation behind. Put the swap and its `on.exit()` restore inside a function.
- 2026-07-30 (M026): `usethis::use_data()` rewrites every dataset its script saves, so an unchanged one still shows as modified through non-deterministic recompression — compare the loaded object against the ref (`load()` from `git show`) and `git checkout` the file back, or the diff claims changes that aren't there.
- 2026-07-30 (M026): roxygen parses `[...]` in any tag as a link, so square brackets around an explanatory note in `@references` emit an "unexpected TEXT, expecting ']'" Rd warning and the note renders wrong — use parentheses or plain prose there.
- 2026-07-30 (M026): the generated paper forms carry "Reverse-scored items are indicated with (R)." in their own instruction text, so a test searching a DOCX for a bare `"(R)"` matches every form ever built and asserts nothing — anchor the pattern to a digit (`[0-9]\(R\)`).
- 2026-07-30 (M027): a nearest-row lookup built on `outer(x, table, "-")` breaks on non-finite or very large `x` — every distance is `Inf` (or collapses to one float past ~1e15), so every row ties and the tie-break decides. Clamp `x` into the table's range before measuring distances.
- 2026-07-31 (M029): converting a `cli_alert_*` report to `cli::cli_warn()` turns console noise testthat ignores into a warning it fails on — every existing test that merely *calls* the function needs sweeping, not just the ones asserting on the message.
- 2026-07-31 (M029): `local_mocked_bindings()` cannot rebind lazy-loaded package data (`pid_norms`), so a branch gated on the data's contents is reached by mocking the predicate that reads it (`norm_covers()`), never the data itself.
- 2026-07-31 (M030, absorbing M027 2026-08-21): a cli plural marker takes its quantity from the LAST value interpolated before it in the same string. With none, `{?s}` aborts at runtime with "Cannot pluralize without a quantity" — and only when that message is actually emitted. With `{cli::qty(n)}` at the head, an intervening `{substitution}` cancels it and the marker silently renders singular. Put `qty()` immediately before the `{?a/b}` it governs.
- 2026-07-31 (M031): a characterization harness that feeds only valid arguments measures returned values and is structurally blind to which inputs are *accepted* — converting argument checks needs a separate differential accept/reject probe (`git archive` the base ref to a temp dir, run both, compare verdicts only), or a narrowed argument silently ships.
- 2026-07-31 (M032, extended M039 and M043): several testthat expectations silently ignore or repurpose a label argument. `expect_setequal()` takes only `(object, expected)` and `expect_length()` only `(object, n)` — neither accepts `info`/`label`, so inside a loop neither can name the failing iteration. Worse, `expect_no_warning(object, message = )` takes `message` as a REGEXP selecting which warnings count, so `expect_no_warning(expr, message = "myfunc")` PASSES even when a warning is raised. Recast all three as `expect_equal(..., info = ...)` — for the last, capture with `withCallingHandlers` and assert the captured vector is `character()`.
- 2026-07-31 (M032): `rlang::call_name(NULL)` errors rather than failing as an expectation, so a `conditionCall()` attribution test whose `call` goes NULL aborts its whole `test_that()` block and hides every later assertion in it — substitute a placeholder call (`quote(no_call())`) so each assertion fails independently.
- 2026-07-31 (M031): `rlang::arg_match()` is not a drop-in for either `match.arg()` or an `x %in% choices` test — it requires an exact match (no partial matching) *and* a character vector, so it rejects a factor that `%in%` accepted.
- 2026-07-31 (M033): `pid_scales[["BF"]]` carries a `camelCase` column too (its five domains and `total`), so a branch guarded on `s %in% pid_scales[[v]]$camelCase` matches BF as well as the facet versions and silently shadows any BF branch below it — key such a test on `v %in% c("FULL", "SF")` instead.
- 2026-07-31 (M033): a cell-by-cell diff written `which(a != b)` reports nothing wherever either side is `NA`, so a CSV cell that fails to parse (a letter `O` for a zero) passes as matching — compare NA-aware (`is.na(a) | is.na(b) | a != b`) and guard the parsed side with `!anyNA()`.
- 2026-07-31 (M034, corrected M035): both mutation harnesses (`data-raw/mutate_norms_check.R` and `data-raw/mutate_norms_book_check.R`, the latter for minutes at a time) swap the tracked `data/pid_norms.rda` in place while they run, so any concurrent reader — a review subagent, a parallel `devtools::test()` — sees a deliberately corrupted dataset and reports phantom mismatches; run either against a `git archive` export of HEAD whenever anything else may be reading the checkout.
- 2026-07-31 (M034): to check a test file's fixture tables from outside, evaluate only its top-level `<-` calls (`for (e in parse(f)) if (is.call(e) && identical(as.character(e[[1]]), "<-")) eval(e, env)`) — regex-scraping `list(...)` literals silently misses any table built from vectors, as `facet_spot`'s 50 rows are.
- 2026-07-31 (M036): a test written to discriminate a derived default from a hardcoded constant must use an input where the two actually differ — a 3-option legend table separates neither, since `seq(1, 3, by = 3)` and `seq(1, 3, by = 4)` both yield one start, so the test passed against the very mutation its comment named; pick an input above the constant (5 options) and re-run the named mutation to confirm red.
- 2026-07-31 (M036): Word cannot be driven from a session on this machine — its AppleScript `save as` errors -1708 and `osascript` holds no accessibility or screen-recording grant, so no DOCX→PDF export and no window capture; `qlmanage -t -s 1600 -o <dir> <file>.docx` renders a page image for a visual layout check, but it is macOS QuickLook's line breaking, not Word's, and any wrap claim must say so.
- 2026-08-01 (M037): the `*_scales` tables store `nItems` as double while `lengths(itemNumbers)` — what the engines return — is integer, so an `identical()` test comparing engine output against the table fails on type alone; use `expect_equal()` there, or compare `as.integer()`.
- 2026-08-01 (M037): a differential probe whose recorder returns the condition whenever one is signalled silently drops the returned value for any call that *warns and still returns* (the misordered-`items` case), so the value comparison it claims never happens for that cell — record value and condition together, not one or the other.
- 2026-07-31 (M035): a name-keyed diff cannot check a value it uses *as* the key — `pid_norms`'s validity scales key on `raw`, so a changed raw score surfaces as a paired extra-row + missing-row instead of a value difference, and the per-column count silently means half what a reader assumes; key on the index the source prints, never on a compared cell.
- 2026-08-01 (M038): pinning a discrete scale's limits (`scale_y_discrete(limits =)`) overrides facet_wrap/facet_grid's per-panel scale training, silently cancelling `scales = "free_y"` and `space = "free_y"` so every panel draws every level — pin only on an unfacetted plot, and assert per-panel axis content (`ggplot_build(p)$layout$panel_scales_y[[i]]$get_limits()`) rather than trusting the facet spec.
- 2026-08-01 (M038): `coord_flip()` applies a facet's free scale *before* the flip, so `scales = "free_y"` frees the post-flip value axis rather than the scale-name axis — map the axes as they are drawn instead of building vertically and flipping.
- 2026-08-01 (M038): a ggplot2 discrete scale trained across layers places a value missing from an earlier layer *last*, not at its factor-level position, so a layer deliberately omitting one level (a profile line skipping a total) silently reorders the axis; assert the drawn order from built coordinates, which run opposite to factor level order.
- 2026-08-05 (M039): a ggplot2 rendering offset (`vjust`/`hjust`) is an absolute distance, while any room reserved for it on a scale is in data units whose physical size shrinks with the panel — so no `expansion()` reservation is device-independent, and a plot fix verified at one figure size can clip again at a smaller one, invisibly to layer data. Offset into the axis with the most room, verify across figure sizes, and state the promise as a figure-size floor rather than unconditionally.
- 2026-08-05 (M039): a layer's `$position` cannot show whether a data-space nudge was applied — ggplot2 gives `geom_label()` a `PositionNudge` whose `$x` is `NULL` with or without `nudge_x`, so `expect_null(layer$position$x)` passes on the very mutation it claims to catch; assert instead that the label layer's built `x` equals the point layer's.
- 2026-08-05 (M039): `rmarkdown::html_vignette` is self-contained, so it base64-embeds figures and deletes the `_files` directory — a render leaves no figure files on disk to inspect unless it passes `output_options = list(self_contained = FALSE)`, and any stale `_files` contents must be cleared first or they inflate the count.
- 2026-08-01 (M038): a Suggests version floor is not enforced when a package is merely loaded, so declaring one in DESCRIPTION alone still lets an old version fail on an unknown argument — pass the same version to the `rlang::is_installed()` guard and hold the two statements of it in step with a test.
- 2026-08-13 (M040): `testthat::test_file(reporter = "silent")` records a thrown error in the result's `error` column, not `failed` — a mutation that makes the code under test abort outright reads as "0 failures" if only `failed` is summed, which silently inverts a mutation check's verdict. Sum `failed > 0 | error`.
- 2026-08-13 (M040): ggplot2 4.x plot objects are S7, so their properties ARE attributes — `attr(p, "data")` returns the internal data frame just as `p$data` does. Any check that means to stop code reading a plot's internals has to cover `attr()` too, not only `$`/`[[`.
- 2026-08-19 (M042): GitHub serves repo files by extension sniff — `.qsf`/`.txt` come back `text/plain` with no `Content-Disposition` (browsers render them; "Save as" names them `.txt`) while `.docx`/`.zip` get `application/octet-stream`; no URL variant (`?download=1`, `blob?raw=1`) changes it and the HTML `download` attribute is ignored cross-origin, so the only fix is same-origin hosting — `pkgdown/assets/<dir>/` copies to the site root, reached from an article as `../<dir>/<file>` (a root-relative `/<dir>/` 404s on a project page).
- 2026-08-21 (M043): an rlang `call =` argument used to blame the right function must default to `rlang::current_env()`, not `rlang::caller_env()` — a default argument is evaluated in the function's OWN frame, so `current_env()` gives that frame while `caller_env()` gives the caller's, and a direct top-level call then produces an error with no call at all. A delegating wrapper passes its own `rlang::current_env()` so its errors name the function the user actually wrote.
- 2026-08-21 (M043): adding an argument can break callers with no rename in sight — `module` made the abbreviation `m = ` ambiguous with the pre-existing `missing = ` in `score_hitopsr()`, which now errors where it worked. R CMD check does not flag it and no deprecation shim can cover it; check new argument names against the partial matches of existing ones.
- 2026-08-22 (M045): R code that must run under WebAssembly cannot shell out — `utils::zip()` calls an external `zip` program via `system2()` and aborts with "The `system()` function is unsupported under Emscripten", where {zip}'s in-C implementation works, and the same shell-out silently fails on any machine with no `zip` on PATH. webR needs no COOP/COEP headers (it falls back to a PostMessage channel), so plain GitHub Pages suffices, but its requests come from a Web Worker and are invisible to a browser network panel. Extended 2026-08-24 (M049): to review what such a page actually builds, patch `HTMLAnchorElement.prototype.click` to fetch the blob URL instead of downloading, then read DOCX/zip members in-page with `DecompressionStream('deflate-raw')` — the page's own R session is module-scoped and unreachable from the console. Extended 2026-08-24 (M050): capture the built file by patching `URL.createObjectURL` to keep the blob and returning early from the anchor's `click`, then read it with `blob.text()`; and drive such a page through `read_page` refs and `form_input`, never screenshot coordinates — the browser pane's screenshot frame and the page's CSS pixels are different scales, so a coordinate click lands rows away from what the screenshot shows.
- 2026-08-22 (M046): an oracle that derives the expected value by inverting the map under test asserts nothing — `item_order[match(v, item_order)] == v` is an identity holding for ANY order, so an acceptance check written that way passed a deliberately wrong order AND passed a mutation of the generator. In a parse-and-compare test, read the expected side OFF the artifact (here each scale's printed numbers from the scoring page), never back through the mapping being verified.
- 2026-08-22 (M047): two traps when an R script shells out to git. `git check-attr` reports `unspecified`, not `auto`, for a path no `.gitattributes` rule covers, so a policy check comparing against `"auto"` finds zero convertible files and passes vacuously — treat `unspecified` as its own violation, since it means behavior falls back to the machine's `core.autocrlf`. And neither `pipe()` nor `system2(stdout = <file>)` keeps a filename away from a shell (the first takes a command line, the second builds a redirect), so a path holding an apostrophe reads as zero bytes and scores clean: pass paths on stdin (`git cat-file --batch`) and check `attr(out, "status")`, because R does not raise on a non-zero exit.
