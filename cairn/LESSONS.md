- 2026-07-16 (M18): DESIGN.md principle bullets must use the validator-canonical `- IPn: …` / `- GPn: …` form — `cairn_validate`'s "principles slot valid" check parses exactly that pattern and first fires when a milestone cites a principle.
- 2026-07-16 (M18): data-raw scripts need readr (+ usethis) installed locally; they are not package dependencies, so a fresh machine must `install.packages("readr")` before regenerating `data/*.rda`.
- 2026-07-16 (M19): the undocumented Qualtrics `GET /survey-definitions/{id}?format=qsf` endpoint returns a genuine importable QSF — validate by shape (SurveyEntry + SurveyElements) and never re-serialize it through jsonlite (round-trips aren't byte-faithful).
- 2026-07-16 (M19): Qualtrics QSF exports serialize a dense zero-based choice map (values 0..n) as a JSON *array*, dropping the keys — recover them positionally from ChoiceOrder when parsing.
- 2026-07-16 (M20): byte-locked repo artifacts need `.gitattributes` `-text` — Windows `actions/checkout` CRLF-converts anything git sniffs as text (.txt/.qsf), silently mutating committed bytes before tests see them.
- 2026-07-16 (M20): DOCX and REDCap zip builds are not byte-deterministic (zip member mtimes, date stamps) — only flat text outputs can be md5-compared across rebuilds; content comparisons must parse inside the container.
- 2026-07-17 (M21): HTML emitted from a knitr chunk via `cat()`/`results='asis'` is still parsed as markdown by pandoc — `_1.0_` became emphasis. Wrap generated HTML in a ```` ```{=html} ```` raw fence so it passes through verbatim.
- 2026-07-17 (M21): pkgdown download-page vignettes render `hitop::hitop_artifacts` from the *installed* package, and `pkgdown/extra.css` copies to `docs/` only on `init_site()`/`build_site()` — after editing data or CSS, `devtools::install()` + a full/`init_site()` build is needed or `build_article()` shows stale content.
- 2026-07-17 (M22): `pkgdown::build_article("name")` (singular) errors "Can't find article" for a newly added `.Rmd` until the article index is rebuilt — use `build_articles()` (plural), or `init_site()`/`build_site()`, after adding a new article.
- 2026-07-30 (M24): three R source files (`R/generate_qualtrics.R`, `R/generate_redcap.R`, `R/reliability.R`) are stored with CRLF while the rest of `R/` is LF — a whole-file rewrite silently converts them to LF and inflates the diff by ~1,700 lines. Edit them in place (Edit tool / targeted patch), never read-modify-write.
- 2026-07-30 (M24): a guard and the code it guards must test truthiness the same way — an `isTRUE(x)` guard in front of an `if (x)` consumer is bypassed by any truthy non-`TRUE` value, and R's `&&` accepts `1`/`1L` but errors on non-coercible strings.
- 2026-07-30 (M25): `on.exit()` at the top level of an Rscript fires at the end of its own top-level statement, not at script end — a script that swaps a tracked file out and back leaves the mutation behind. Put the swap and its `on.exit()` restore inside a function.
- 2026-07-30 (M26): `usethis::use_data()` rewrites every dataset its script saves, so an unchanged one still shows as modified through non-deterministic recompression — compare the loaded object against the ref (`load()` from `git show`) and `git checkout` the file back, or the diff claims changes that aren't there.
- 2026-07-30 (M26): roxygen parses `[...]` in any tag as a link, so square brackets around an explanatory note in `@references` emit an "unexpected TEXT, expecting ']'" Rd warning and the note renders wrong — use parentheses or plain prose there.
- 2026-07-30 (M26): the generated paper forms carry "Reverse-scored items are indicated with (R)." in their own instruction text, so a test searching a DOCX for a bare `"(R)"` matches every form ever built and asserts nothing — anchor the pattern to a digit (`[0-9]\(R\)`).
- 2026-07-30 (M27): a nearest-row lookup built on `outer(x, table, "-")` breaks on non-finite or very large `x` — every distance is `Inf` (or collapses to one float past ~1e15), so every row ties and the tie-break decides. Clamp `x` into the table's range before measuring distances.
- 2026-07-30 (M27): cli's inline plural `{?a/b}` needs a quantity interpolated earlier in the same string — a bare `{?s}` with no preceding `{n}` aborts at runtime with "Cannot pluralize without a quantity", and only fires when that message is actually emitted.
- 2026-07-31 (M29): converting a `cli_alert_*` report to `cli::cli_warn()` turns console noise testthat ignores into a warning it fails on — every existing test that merely *calls* the function needs sweeping, not just the ones asserting on the message.
- 2026-07-31 (M29): `local_mocked_bindings()` cannot rebind lazy-loaded package data (`pid_norms`), so a branch gated on the data's contents is reached by mocking the predicate that reads it (`norm_covers()`), never the data itself.
- 2026-07-31 (M30): cli takes a plural marker's quantity from the last value interpolated before it, so `{cli::qty(n)}` at the head of a string is cancelled by an intervening `{substitution}` and the marker silently renders singular — put `qty()` immediately before the `{?a/b}` it governs.
- 2026-07-31 (M31): a characterization harness that feeds only valid arguments measures returned values and is structurally blind to which inputs are *accepted* — converting argument checks needs a separate differential accept/reject probe (`git archive` the base ref to a temp dir, run both, compare verdicts only), or a narrowed argument silently ships.
- 2026-07-31 (M32): `testthat::expect_setequal()` takes only `(object, expected)` — no `info`/`label` — so inside a loop it cannot name the failing iteration; `expect_equal(sort(unique(a)), sort(unique(b)), info = ...)` compares as a set, carries the label, and still reports which elements differ.
- 2026-07-31 (M32): `rlang::call_name(NULL)` errors rather than failing as an expectation, so a `conditionCall()` attribution test whose `call` goes NULL aborts its whole `test_that()` block and hides every later assertion in it — substitute a placeholder call (`quote(no_call())`) so each assertion fails independently.
- 2026-07-31 (M31): `rlang::arg_match()` is not a drop-in for either `match.arg()` or an `x %in% choices` test — it requires an exact match (no partial matching) *and* a character vector, so it rejects a factor that `%in%` accepted.
- 2026-07-31 (M33): `pid_scales[["BF"]]` carries a `camelCase` column too (its five domains and `total`), so a branch guarded on `s %in% pid_scales[[v]]$camelCase` matches BF as well as the facet versions and silently shadows any BF branch below it — key such a test on `v %in% c("FULL", "SF")` instead.
- 2026-07-31 (M33): a cell-by-cell diff written `which(a != b)` reports nothing wherever either side is `NA`, so a CSV cell that fails to parse (a letter `O` for a zero) passes as matching — compare NA-aware (`is.na(a) | is.na(b) | a != b`) and guard the parsed side with `!anyNA()`.
- 2026-07-31 (M33): the browser pane refuses `file://` URLs, so reading a shelf source's rendered page means serving its extracted directory through a `.claude/launch.json` static-server entry and navigating to it — `python3 -m http.server -d <dir>` on its own port, removed again afterwards.
- 2026-07-31 (M34, corrected M35): both mutation harnesses (`data-raw/mutate_norms_check.R` and `data-raw/mutate_norms_book_check.R`, the latter for minutes at a time) swap the tracked `data/pid_norms.rda` in place while they run, so any concurrent reader — a review subagent, a parallel `devtools::test()` — sees a deliberately corrupted dataset and reports phantom mismatches; run either against a `git archive` export of HEAD whenever anything else may be reading the checkout.
- 2026-07-31 (M34): to check a test file's fixture tables from outside, evaluate only its top-level `<-` calls (`for (e in parse(f)) if (is.call(e) && identical(as.character(e[[1]]), "<-")) eval(e, env)`) — regex-scraping `list(...)` literals silently misses any table built from vectors, as `facet_spot`'s 50 rows are.
- 2026-07-31 (M36): a test written to discriminate a derived default from a hardcoded constant must use an input where the two actually differ — a 3-option legend table separates neither, since `seq(1, 3, by = 3)` and `seq(1, 3, by = 4)` both yield one start, so the test passed against the very mutation its comment named; pick an input above the constant (5 options) and re-run the named mutation to confirm red.
- 2026-07-31 (M36): Word cannot be driven from a session on this machine — its AppleScript `save as` errors -1708 and `osascript` holds no accessibility or screen-recording grant, so no DOCX→PDF export and no window capture; `qlmanage -t -s 1600 -o <dir> <file>.docx` renders a page image for a visual layout check, but it is macOS QuickLook's line breaking, not Word's, and any wrap claim must say so.
- 2026-07-31 (M35): a name-keyed diff cannot check a value it uses *as* the key — `pid_norms`'s validity scales key on `raw`, so a changed raw score surfaces as a paired extra-row + missing-row instead of a value difference, and the per-column count silently means half what a reader assumes; key on the index the source prints, never on a compared cell.
