# M053: A format-first flow for the browser module builder

**Status:** done (2026-08-24, PR #59 https://github.com/jmgirard/hitop/pull/59)

**Goal:** The HiTOP-SR Module Builder asks which output format the visitor wants before it asks anything about that format, so each visitor configures and downloads one format and never reads another's settings.

**Outcome:** In `jmgirard/hitop-builder` (PR #4, commit `6375a54`): `index.html`'s step two becomes a `div.formats` grid of three `button[data-choose]` cards, each recording the format and calling `showStep(2)` in one handler, so the choice IS the move. Step three holds all three `.fmtpanel` blocks with only the chosen one unhidden: Word's *Paper size* / *Item numbering* / *Item order*, Qualtrics' *Block and question naming* (`#naming`), REDCap's *Form name and required items* (`#redcapNaming`) — the M050 shared naming fieldset split in two, one group per format. `setFormat()` swaps the panel, the `#step3h` heading and the single `#downloadBtn`'s label from a `heading`/`button` pair added to each `FORMATS` entry; `markFormatChoice()` writes the `aria-current` mark and is called only from a card's click handler, so the module-level `currentFormat = 'docx'` starting value keeps a step-bar jump to step three coherent without announcing a choice nobody made. `download()` takes no argument and reads `currentFormat`; its per-format `extra` string is unchanged, so `randomize`/`renumber`/`papersize` still reach only the DOCX call and neither online format's naming reaches the other. Step three's foot carries a standing *Choose a different format* button (`data-goto="1"`); step two's *Continue to download* is gone. Step-bar labels become *Choose scales* / *Choose a format* / *Options and download*. `README.md`'s *What the page shows* walks the three steps in page order with a per-format settings list, and the three "Under **Set options**" sections re-point at the format screens. The R package is untouched — this repo's diff is tracking files only.

**Decisions:** None milestone-local. Three plan gates (three steps with options and download merged over a four-step flow; an explicit return-to-the-format-choice control over the step bar or three download buttons; the full 16-cell AC1 matrix over a reduced six-cell one) and one implementation gate (format buttons advancing on click over radios plus Continue; group titles dropping the format prefix; a standing *Choose a different format* button; the three step-bar labels).

Per-format Tab enumerations exactly the named controls, plus an executed cross-contamination probe: each format's file is identical with every other format's controls moved to non-defaults. Two-format path driven with the ticks untouched, both files carrying the same ten items. All six step boundaries crossed from Tab-reached controls with the heading focused and ringed; live regions exactly `#status` (polite) and `#log` (`off`); download disabled at zero scales with its hint. 1248 containment checks over 6 width × scheme cells × 5 views, 0 clipped, no horizontal scroll.
