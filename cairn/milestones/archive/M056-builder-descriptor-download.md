# M056: The browser builder offers the module descriptor as a download

**Status:** done (2026-08-25, PR #62 https://github.com/jmgirard/hitop/pull/62; app change jmgirard/hitop-builder#5)

**Goal:** Give a visitor to the browser module builder the descriptor file that scores the data their generated form collects, including a shuffled form's printed order.

**Outcome:** The builder page passes M055's `descriptor` on all three generator calls and hands over both files per build: `saveFile()` writes questionnaire then descriptor, both read out of webR's FS before either is saved, so a failed build hands over neither. The descriptor takes the questionnaire's own stem (`hitopsr-module.json`; `hitopsr.json` when all 76 scales are ticked). A standing notice above the download button states what the file is for and to keep it with the responses, and `crosswalkSentence()` gained tails naming the `.json` in the two of its four branches where the printed order is recoverable only from it. README gained a *The scoring file* section.
