# M126: The module builder's format step gains an "Online form" card that saves the `write_module()` scoring file and links to hitop-form's link builder with the module filled in

**Status:** done (2026-09-25, PR #137 https://github.com/jmgirard/hitop/pull/137; code in jmgirard/hitop-builder PR #22 https://github.com/jmgirard/hitop-builder/pull/22, merged 2026-09-25T19:20:19Z)

**Goal:** Offer the online form beside Word, Qualtrics and REDCap in the builder's format step, so choosing it saves the scoring descriptor and opens hitop-form's link builder with the module already in place.

**Outcome:** In hitop-builder `index.html`, `FORMATS.online` and a fourth card. The `online` branch of `download()` binds the ticked scales, runs `write_module(hitop_module("hitopsr", scales = ...), file)` in webR, and saves the bytes as `hitopsr-online.json` (every scale) or `hitopsr-online-module.json`. `showLinkBuilder()` clones an anchor from a `<template>` (static text, `target="_blank"`, `rel="noopener"`). Its href is `link.html?c=` carrying base64url `{instrument, module}` made from the saved text. The link is put in only while `selected()` still equals the selection the file was built from. `removeLinkBuilder()` runs from `selectionChanged()` (every tick, Select all, Clear all) and at the start of every build. `setFormat()` swaps the notice and hint pair. Smoke A12 to A17, plants (m) to (w), `npm run prose`, and a `smoke.yml` step that runs it after `npm ci`. README: the card, a section "The online form", two naming rows. This repo: tracking only.

**Decisions:** none cross-cutting. Plan gate: a saved `.json` plus an anchor rather than opening the link builder from the click handler, because a tab opened after an async save is blocked as a popup. The prose ledger's CI step was added here rather than promoting the whole candidate row.
