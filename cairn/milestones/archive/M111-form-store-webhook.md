# M111: hitop-form sends each participant's responses to an endpoint named in the study link

**Status:** done (2026-09-23, PR #122 https://github.com/jmgirard/hitop/pull/122; code in hitop-form PR #2 https://github.com/jmgirard/hitop-form/pull/2, merged as b0c38a3).

**Goal:** Extend `jmgirard/hitop-form` so a study link can name a store, and the page then posts the finished responses to it and saves them to the participant's device only when the send cannot be confirmed.

**Outcome:** In hitop-form, a study link's `store` (`{ kind: "webhook", url }`) is checked by `checkStore()`/`checkStoreUrl()` in form.js (`https:` to any host, `http:` only to `127.0.0.1` or `localhost`, no user name or password, every refusal named) and by link.html's new "Send responses to" field. At Finish, `buildRow()` makes one JSON object (`study`, `participant`, `instrument`, `form_build`, `submitted`, then one integer per item in shown order) and `sendResponses()` posts it as a CORS simple request (`text/plain;charset=utf-8`, `redirect: 'follow'`, `credentials: 'omit'`, `referrerPolicy: 'no-referrer'`, a 30-second `AbortController`). A send is confirmed only by a 2xx with a JSON body whose `ok` is `true`; every nav button is disabled from the first press until an outcome screen. Confirmed: the sent screen, no file. Anything else: the CSV saved through `saveFile()` from a snapshot of the answers, and the unconfirmed screen naming the file and the reason. The start screen names the store's host with a store and keeps the old wording without one. Tests: `serveStore()` in tests/serve.mjs (a recording endpoint on its own port with a third-origin twin for `/redirect`, plus `/html`, `/status/<n>`, `/hang/`), `useStore()`/`allowLocalStore()`/`webhook()` helpers, `tests/send.spec.js` (T1–T8, the sheet-fixture test included), N4–N5 in network.spec, G7 in guard.spec, L4–L5 in link.spec, R6 in render.spec. The README gained "Send responses to a Google Sheet" with a `doPost` for an Apps Script web app: a script lock (10 s), keys checked against `^[a-z0-9_]+$` and capped at 1000, every cell written behind an apostrophe and formatted as text, `{"ok":true}` or `{"ok":false, why}` as JSON; plus the CORS requirement, the late-answer duplicate and the forged-row risk. `tests/fixtures/sheet-hitopbr.csv` is the sheet's download from two walks (`=1+1`, `007`) against that code, equal to the posted bodies in 100 of 100 fields. Suite 35 → 70 tests. hitop changed `cairn/` only.
