# M051: A visual system and tightened copy for the browser module builder

**Status:** done (2026-08-24, PR #57 https://github.com/jmgirard/hitop/pull/57)

**Goal:** The HiTOP-SR Module Builder page carries a stated type, spacing and colour system in place of default browser styling, and copy rewritten to the same standard, with every file it builds unchanged.

**Outcome:** In `jmgirard/hitop-builder` (PR #2, commit `88dc5b1`): a token layer in `index.html`'s `<style>` — colour pairs stated per scheme with `color-scheme` set so the browser paints controls to match, a 4px spacing scale, a type scale, `--r1`/`--r2` radii — applied to the existing markup without moving an element. README gains a *What the page shows* section. The R package is untouched.
