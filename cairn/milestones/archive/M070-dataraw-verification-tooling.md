# M070: `data-raw/` verification tooling is reduced to what still re-runs, with its live guard defects repaired

**Status:** done (2026-08-30, PR #76 https://github.com/jmgirard/hitop/pull/76)

**Goal:** `data-raw/` keeps only verification scripts a maintainer can still re-run, with the two defects repaired in the guards those scripts share.

**Outcome:** Deleted `verify_hitopsr_rename.R`, `verify_m060_characterization.R` and `verify_m061_characterization.R` — one-shot merge-base diffs whose base has moved, load-bearing for nothing live. In `hitopsr_table1.R` the inline stray-text `grepl` became the named `hitopsr_table1_is_watermark()`, reading the `hitopsr_table1_watermark_fragments` vector that `hitopsr_table1_rows()`'s stripping step also builds its pattern from; its comment now states the ordering, non-overlap and no-metacharacter rule the two consumers depend on. This repair is provenance and naming only — the predicate classifies every token identically to the line it replaced, measured at review. In `mutate_norms_book_check.R` the sweep gained a three-way verdict (caught / not caught / errored), decided from the assembly comparison's own count line rather than the exit status a crash and a catch share, and — after a review finding — the harness's own `load`/`m$f`/`save` step files its errored verdict too, so a mutation function that stops no longer kills the sweep. All files are `.Rbuildignore`d maintainer tooling; nothing user-visible changed.

**Decisions:** M070-D1 — the Table 1 stray-text guard admits any part of the watermark phrase, single letters included, and that is the guard's floor rather than a gap left open: `pdftotext -bbox` splits the rotated stamp into single letters in the numeric columns, and `cells` is defined as the digit-bearing tokens, so no token reaching the guard can be a lost numeric cell.
