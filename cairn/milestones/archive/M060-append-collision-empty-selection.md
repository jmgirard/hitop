# M060: The scoring and conversion family refuses two argument shapes it lets fall through

**Status:** done (2026-08-28, PR #67 https://github.com/jmgirard/hitop/pull/67)

**Goal:** Every exported function that appends columns to `data` refuses an output-column collision, and every function taking a variable-length column selection refuses an empty one, each with a classed condition naming what the caller wrote.

**Outcome:** Two internal validators in `R/util.R`. `validate_no_output_collision(produced, data, arg)` aborts with the public class `hitop_append_collision`, naming every colliding column in the caller's own column order — collapsed through `cli::cli_vec(style = list(vec_trunc = Inf))` to defeat cli's 20-item inline elision — wired into the five append sites (`score_engine`, `validity_pid5`, `rank_scales`, `norm_pid5`, `interval_engine`) covering the seven exports carrying an `append` formal, each placed after that site's existing argument checks and ahead of its warnings. `validate_nonempty_selection(x, arg)` aborts with the public class `hitop_empty_selection` in `norm_pid5()`, `interval_engine()` and `rank_scales()`, after the selection's type check and ahead of `top`/`srange`/`prefix`/`level`/`append`, with `data` still reported first; it replaces base R's differing-number-of-rows error and `rank_scales()`'s `top` "between 1 and 0", which blamed a consequence for its cause. `validity_pid5()`'s four cutoff abbreviations are resolved once into `cutoff_vars` so the collision enumeration and the scale blocks cannot drift. Three new test files (`test-append-collision.R`, `test-empty-selection.R`, `test-error-prose.R`, 271 passes) plus `data-raw/verify_m060_characterization.R`, a maintainer-run harness comparing value, conditions and accept/reject verdict per export against a `git archive` of the merge base. No arithmetic changed and no succeeding call's return value moved, except the two `append = FALSE` empty-selection calls that used to return an empty tibble.

**Decisions:** D-045 (written at plan time, on `main`): the contract and the two public condition classes, meeting D-034(c). Milestone-local gate choices are in the work log — aborting over silently returning `data`, aborting over overwriting, all seven exports over the two the candidate row named, the narrow 7-call harness over an argument grid, a `data-raw/` script over a testthat helper, and existing checks reported ahead of the collision.
