# M123: `read_form_responses()` refuses a whitespace-only line, a byte that is not UTF-8, and an `instrument` cell that differs from the item stem, and names each cell in its value refusals

**Status:** done (2026-09-24, PR #134 https://github.com/jmgirard/hitop/pull/134)

**Goal:** A hand-edited or mis-encoded hitop-form file stops at `read_form_responses()` with a message that names the file and the line, row or cell at fault, instead of a base R error, a wrong row count, or a silent read.

**Outcome:** `read_form_response_file()` reads the file's bytes through a new `form_file_lines()`: `readBin()`, each NUL byte located by counting line feeds and replaced by a space, a leading byte-order mark dropped, a split on `\n` with the trailing `\r` removed, and `validUTF8()` over the lines. A NUL or non-UTF-8 line is refused first, naming each line by its kind ("holds a NUL byte or a line that is not UTF-8"), with no base R warning. `count_form_fields()` now counts those lines over a `textConnection` with `blank.lines.skip = FALSE`, a carriage return inside a line counted as a space, so counts align with lines (an empty line 0, a line inside a quoted cell NA); a line matching `^[ \t]+$` whose count is not NA is refused as "made only of spaces and tabs", after the byte check and before the field count, the counts read by line so a quote left open to the end of the file adds no phantom line. After the stem check, guarded on one stem, an `instrument` cell differing from the stem (blank or padded included) is refused per response row with the cell and the stem. The whole-number and integer-range refusals name each cell through `form_cell_lines()`: "Response row r, column c: value" in row then column order, five at most, then "... and n more cells."; `form_bullets()` doubles braces so `cli_abort()` shows a value as written. Both line refusals count from the file's first line, the row refusals from the first row after the header; `?read_form_responses` Details and NEWS say so. Two hitop-form fixtures (`responses-module-shuffled.csv`, `responses-pid5.csv`) copied in, byte-identical to `inst/examples/`. Tests: 42 added, reader file 125 tests and 763 expectations.

**Decisions:** none milestone-local. D-064 governs (unclassed refusals naming the file).
