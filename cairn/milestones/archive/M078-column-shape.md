# M078: The per-scale tables the package ships or returns join on one column shape

**Status:** done (2026-09-01, PR #84 https://github.com/jmgirard/hitop/pull/84)

**Goal:** A caller joining the package's per-scale tables to each other or to scored output meets one integer `nItems` and a `camelCase` stem column on every one of them, and the two devstats tables and the reliability return spell their display-name column `Scale` as `available_scales()` does, with no value moved.

**Outcome:** `data-raw/pid_info.R`, `hitopsr_info.R` and `hitopbr_info.R` build `nItems` with `purrr::map_int()`/`as.integer()`, so `pid_scales` (all three elements), `hitopsr_scales`, `hitopsr_subscales` and `hitopbr_scales` ship it as integer, and `available_scales()` drops the compensating `as.integer()` M061 added. `reliability_engine()` takes a `scale_stems` argument guarded to the same length as `scale_names`, supplied from the keying table's `camelCase` column on the rows `Scale` is read from (`R/reliability_pid5.R`, `R/reliability_hitopbr.R`, `hitopsr_engine_inputs()`/`module_engine_inputs()` in `R/module.R`), so the three `reliability_*()` returns carry `camelCase` second and `nItems`/`alpha`/`omega` each shift one position right. `data-raw/hitopsr_devstats.R`, `hitopbr_devstats.R` and their two verifiers rename `scale` to `Scale`. `tests/testthat/test-column-shape.R` is new: the shipped-table walk (hit set pinned, so it cannot pass over an empty domain), the merge-base identity tests for all six objects, the six-call by three-flag return-shape and stem-alignment tests, and the devstats names. Breaking with no deprecation cycle, under the pre-1.0 waiver.

**Decisions:** D-053. Four plan-gate alternatives are recorded in the milestone file's work log (a dual-column release, coercing the shipped objects in place, retyping three tables rather than four, appending `camelCase` last).
