# M096: The package reads hitop-form response files into one data frame and scores them through a module descriptor

**Status:** done (2026-09-20, PR #104 https://github.com/jmgirard/hitop/pull/104)

**Goal:** Add an exported reader that turns hitop-form CSV files into one tibble the scoring functions take as they are, document the hand-off in the modules article, and prove a saved form round-trips through `score_hitopsr()` with `read_module()`.

**Outcome:** `read_form_responses(path)` in `R/read_form_responses.R`: a directory (every `.csv` or `.CSV` file, folders skipped) or a vector of paths, sorted in the C locale (`sort(method = "radix")`), each read by `utils::read.csv` as character with `fileEncoding = "UTF-8-BOM"`, CRLF and LF accepted, a missing final row ending muffled; one row per file; `study`, `participant`, `instrument` character, `form_build` Date (matched whole as `YYYY-MM-DD`), `submitted` POSIXct UTC (matched whole, fractional seconds through `%OS`), item columns integer in the first file's order, a blank as `NA`. Classed refusals (D-064): `hitop_form_responses_mismatch` when item columns differ in name, count or order, one message line per differing file with its own reason; `hitop_form_responses_none` for a directory with no CSV. Unclassed refusals naming the file: not a file, other lead columns, a duplicated column, more than one row, a non-integer or out-of-range item value, a stamp that does not parse. Fixtures `tests/testthat/fixtures/responses-{hitopbr,hitopsr,module-shuffled}.csv` and `module-shuffled.json` from hitop-form 21a1d1c, provenance in the fixtures README. `test-read_form_responses.R`: 29 tests, 89 expectations; the full forms scored against means recomputed from `*_items$Reverse` and `*_scales$itemNumbers`, the module against hand-worked literals 3 and 2.4375 with an instrument-order control. `modules-hitopsr.Rmd` gains "Collecting Responses Online with hitop-form" (link builder, file shape, reading, scoring by position under `layout = "printed"`). NEWS entry; `_pkgdown.yml` row.
