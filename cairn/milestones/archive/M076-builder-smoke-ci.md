# M076: The builder page's boot path is bounded end to end and watched by a headless smoke test in CI

**Status:** done (2026-08-31, PR #82 https://github.com/jmgirard/hitop/pull/82 and hitop-builder PR #12 https://github.com/jmgirard/hitop-builder/pull/12)

**Goal:** CI drives the browser module builder through a real headless boot and Word download, and the page stops waiting forever on a webR runtime that never arrives.

**Outcome:** In `jmgirard/hitop-builder`: `RUNTIME_TIMEOUT_MS` (120000, beside `INSTALL_TIMEOUT_MS`) races `import(WEBR_URL)` and `webR.init()` together, and on expiry `abandonBoot()` names R's own download rather than the package install. `tests/smoke.spec.js` drives the page headlessly to a Word download under six enumerated assertions A1-A6 (status `Ready.`; more than `MIN_SCALE_ROWS` = 50 scale rows, each with a non-empty `.nm` name; an enabled `#downloadBtn`; ZIP magic bytes; more than `MIN_DOCX_BYTES` = 10,000 bytes). `tests/plants.mjs` runs it against six planted copies of `index.html` and fails unless every enumerated assertion — read out of the spec file, not restated — is failed by at least one plant, and unless each plant fails a named one. `tests/runtime-timeout.spec.js` stalls each half of the runtime download against `tests/serve.mjs`'s `/hang/` path. `.github/workflows/smoke.yml` runs the smoke test on `pull_request` and `push` to `main` against the checkout, and on a weekly `schedule` and `workflow_dispatch` against the deployed page, with `SMOKE_REQUIRE_TARGET` failing a deployed-page run that would silently fall back to the checkout. `pages.yml` publishes `index.html`, `LICENSE.md` and `README.md` and nothing else — verified live after merge (those three 200, `package.json` and `tests/` 404). Here: `cairn/PROFILE.md` gained a Downstream watch bullet naming the smoke test and its four triggers.
