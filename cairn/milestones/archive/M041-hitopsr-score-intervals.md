# M041: Confidence intervals for HiTOP-SR scale scores

**Status:** done (2026-08-28, PR #66 https://github.com/jmgirard/hitop/pull/66)

**Goal:** Give each HiTOP-SR scale score a regression-based true-score estimate and a confidence interval, computed from the instrument paper's published development-sample statistics and labelled as such everywhere it appears.

**Outcome:** Exported `interval_hitopsr(data, scores, srange, prefix, level, append)` returns `_est`/`_lo`/`_hi` per score column from Schmukle (2026) Eqs (10)-(12) — `est = M + sqrt(rel)*(x - M)`, half-width `z * SD * sqrt(1 - rel)`, bounds deliberately unclamped. The unexported `R/interval_engine.R` takes its reference statistics as an argument, so a HiTOP-BR or PID-5 wrapper can reuse it. Exported `hitopsr_devstats`: 93 rows x 8 columns (`scale`, `camelCase`, `type`, `nItems`, `reliability`, `reliabilityType`, `mean`, `sd`) transcribed from Table 1 of the HiTOP-SR introduction manuscript, Development Sample 2 (N = 780), built by `data-raw/hitopsr_devstats.R` and diffed cell-by-cell against an independent `pdftotext -bbox` coordinate extraction by `data-raw/verify_hitopsr_devstats.R` (744 cells, none differing). Also new: `validate_level()` in `R/util.R`; public conditions `hitop_interval_uncovered` and `hitop_interval_coding`; `cairn/ORACLES.md` holding four oracle records, declared from `cairn/DESIGN.md`; source notes `cairn/references/{simms2026,schmukle2026}.md`.

**Decisions:** D-043 (Table 1's printed Cronbach's alpha is the reliability input; omega-ordinal rejected for this use) and D-044 (the two condition classes, public) are promoted. Locally: the bounds are not clamped to `srange`, and AC5's coverage oracle verifies the implementation under the source's linear-normal model rather than robustness to skew.

**Review:** One pass, no returns; three-lens fan-out, CI green on all eight jobs. The blame and prior-review lenses reported nothing; the Opus diff lens returned 11 findings and the review session 2. None showed a criterion failing, so the return floor never fired.
