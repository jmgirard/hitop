# M062: Both files a builder download produces reach the visitor's disk

**Status:** done (2026-08-29, PR #69 https://github.com/jmgirard/hitop/pull/69; builder PR #7 https://github.com/jmgirard/hitop-builder/pull/7, merged `9f8b615`)

**Goal:** Hand the module descriptor over as a button the visitor clicks, so no browser can withhold it as the second of two synthetic clicks and leave the questionnaire saved with nothing to score it by.

**Outcome:** `saveFile()` takes a `data-origin` provenance flag; `download()` saves only the questionnaire (origin `build`) and calls `offerDescriptor()`, which holds the descriptor's bytes and filename, names them on `#saveDescriptor` and logs any replacement; `takeDescriptor()` saves it with origin `visitor`. The held pair carries a `taken` flag, so a replacement claims a loss only when one occurred. `#saveDescriptor` sits outside `.downloads` (which `refreshTally()` disables) in a shared `.downloadrow`, and is disabled for the duration of a build. `#handoverLive` announces the offer, replacements and saves. `#descriptorNote`, `#downloadHint`, both `crosswalkSentence()` branches and README's *What the page shows*, *The scoring file* and *Shuffling the Word form* rewritten. The R package is untouched.

**Decisions:** milestone-local — the descriptor stays offered after it is taken, until the next completed build replaces it. No cross-cutting D-entry.
