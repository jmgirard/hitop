# M071: The Table 1 extractor and the staged-artifact guards no longer return a verdict a wrong input cannot change

**Status:** done (2026-08-30, PR #77 https://github.com/jmgirard/hitop/pull/77)

**Goal:** Every reported `data-raw/` and test-suite gap that can change a verification verdict is repaired, and the gaps that cannot are closed rather than carried.

**Outcome:** Six repairs, all in `.Rbuildignore`d maintainer tooling and the package's own suite; no keying content, scored value or distributed artifact moved. `hitopsr_table1_cells()` assigns `block` from `hitopsr_table1_superspectra_scales` — eight pinned labels — and stops naming any row whose name and header side disagree, replacing a positional split that any 8-row revision passed. `hitopsr_table1_rows()` marks a section header by `hitopsr_table1_section_headers` — thirteen pinned labels — replacing a `\bScales\b` test that misclassified in both directions, and stops on a pinned header it cannot find. The three watermark strips move into `hitopsr_table1_strip_watermark()`, each bounded by `(?<![A-Za-z])`/`(?![A-Za-z])`, so `committee1` is no longer rewritten to `committ1`; measured over the pinned proof, the two digit-anchored calls became subsets of the third. `test-artifacts.R` asserts `pkgdown/assets/downloads/` exists whenever the suite runs from a checkout, the floor under two sweeps that both tolerated its absence. `verify_hitopsr_names.R`'s fragment control reads `hitopsr_table1_watermark_fragments` instead of a hardcoded copy. `rendering_pattern()` replaces a trailing `y` with a case-folded `(y|ies)` instead of trailing the alternation after the whole name; the scope's claim that it matched no all-uppercase rendering was refuted — the per-letter fold already did. `xml` and `txt` became arguments to the two extractors so the verifiers can feed mutated dumps. Nine reported gaps that change no verdict were dropped at the plan gate rather than carried, and norms CSVs as CI fixtures were rejected as asserting the build's own output as truth.

**Decisions:** none.
