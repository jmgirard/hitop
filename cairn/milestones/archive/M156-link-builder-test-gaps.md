# M156: Study Link Builder test gaps

**Status:** done (2026-10-02, PR #165 https://github.com/jmgirard/hitop/pull/165; companion hitop-form PR #29 https://github.com/jmgirard/hitop-form/pull/29)

**Goal:** hitop-form's tests catch the stray requests, closed sections and wrong site choices they now miss, and give the same result on every run.

**Outcome:** Test-only changes in hitop-form `tests/`. `link-sections.spec.js` records each request of the browser context as it starts and judges strays in `afterEach`. Export routes mark their request first, through `markAnswered()`, `fulfillExport()` and `routeExport()` in `helpers.mjs`. S1 fails on an unknown child of `#f`. S4 loops each site with each destination at both widths and checks `SITES` and `KINDS` against the page's menus. Every `ONE_FIELD` entry asserts the site menu. `openSectionOf()` takes `wasOpen`, used at the four calls after a `c`, `z` or setup-file load, and LF5 asserts all five sections. With `FORM_TARGET` empty, the auto fixture `exportCopies` answers exports from five committed copies in `tests/fixtures/exports/` and fails on an unanswered export request. `begin()` takes that route off, since a context route suppressed the store's CORS preflight. Every spec imports `test`/`expect` from `helpers.mjs`. With `FORM_TARGET` set, `fetchExport()` fetches live and `exports.spec.js` E1 fails on a drifted copy. `observeUntilLeave()` reports mutations and the `navigate` event through one exposed function, which fixed N7's 2-in-100 failure, a Finish click waiting on the held navigation. `begin()` waits for Begin to the test timeout. README rows, the fixtures README and the workflow and config comments follow.

**Decisions:** none cross-cutting. The plan gate chose committed copies on PR and push runs with a weekly copy-against-live test, and a context `request` listener judged in `afterEach`. The implement gate chose one shared mark helper, one ordered page channel and `helpers.mjs` as the fixture's home.

**Review:** Three passes, each a three-lens fan-out. Pass 1 returned AC6 (defect return 1): two T3 checks missing from README rows. Pass 2 returned AC6 again (defect return 2, thrash trigger b, return chosen over escalation): the send row said the screen was read while the request was held, but the read is at the `navigate` event. A fresh reader then checked every changed row. Pass 3 found no criterion failing. Seven fixes landed at the gate: "at the request" and "live" wording, `begin()`'s 15 s cap, an S4 count check that always passed, the fixtures README, an unused import and the retry comment. D4/B3 (second page, context-wide unroute) and pass 2's D2/D4 went to the fixture-reach candidate row. Both PRs passed CI and had no review comments. The M119 lesson was corrected to point at `observeUntilLeave()`.
