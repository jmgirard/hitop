# M109: Scoring refuses an item column it cannot read as numbers

**Status:** done (2026-09-22, PR #120 https://github.com/jmgirard/hitop/pull/120)

**Goal:** If a researcher scores an export of choice text or factor codes, the call aborts and names the bad columns. It does not return all-`NA` or wrong scores.

**Outcome:** `validate_item_columns()` and `unparsed_value()` in `R/util.R` apply one value rule. A numeric or logical column is accepted. When all its values parse with `as.numeric()` after `trimws()`, a character column is accepted. Blank and `NA` cells are skipped. The rule reads columns by position. `prep_items()` and `validity_pid5()` call it after the argument checks and before the collision check, the `srange` warning and conversion. The rule covers seven functions: the three `score_*()` functions, the three `reliability_*()` functions and `validity_pid5()`. The abort has class `hitop_nonnumeric_items`. It names the first five refused columns in the caller's `items` order and counts the rest. Each named column shows its class, and a character column also shows its first bad value. It shows a factor tip only for a factor. A `caller_items` argument carries the caller's order through the engines under `layout = "printed"`. The `items` docs, the Errors sections and NEWS are updated. haven is in Suggests, for tests only.
