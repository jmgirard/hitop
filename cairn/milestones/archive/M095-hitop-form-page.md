# M095: A static page renders a HiTOP-SR or HiTOP-BR form from the package's JSON export and saves each participant's responses to their device

**Status:** done (2026-09-20, PR #103 https://github.com/jmgirard/hitop/pull/103)

**Goal:** Publish `jmgirard/hitop-form`, a static page that renders a HiTOP instrument or a HiTOP-SR module from the package's JSON export, walks a participant through it, and saves one response file to the participant's device, transmitting nothing.

**Outcome:** The public repository `jmgirard/hitop-form`, deployed at https://jmgirard.github.io/hitop-form/ (GitHub Pages, workflow build, no build step): `index.html` plus `form.js` read a study link `?c=<base64url JSON>` (`instrument`, `study`, optional `participant`, optional `module` as `write_module()` writes it), fetch `https://jmgirard.github.io/hitop/downloads/<stem>.json` cross-origin, refuse an export whose `format` is not `"1.0"` or whose `stem`, `buildDate`, `packageVersion` or `package` is missing or whose stem differs from the link, render the export's items (or the descriptor's, in `itemOrder` else `items` order) 15 to a page numbered by form position, refuse to advance past a blank item naming both its form number and its place on the page, and save one RFC 4180 CSV (`study,participant,instrument,form_build,submitted,<item names>`, CRLF, UTF-8, `submitted` to the second in UTC) through a Blob. `link.html` builds the link and runs the page's `checkModule` on a pasted descriptor (format "1.0", instrument match, integer items, `itemOrder` a permutation; a pasted export is named as such). Each screen's heading takes focus; a `beforeunload` warning guards unsaved answers. Playwright suite of 22 tests (`render`, `walk`, `save`, `guard`, `network` specs) against the live export, with fixtures `module-{plain,shuffled}.json` from `make-descriptors.R` (seed 95) and three captured `responses-*.csv` for M096. `tests.yml` runs on pull requests and pushes to main, and Mondays and on dispatch against the deployed page (`FORM_REQUIRE_TARGET` set on every other event); `pages.yml` stages five files. In hitop: one `hitop-form` entry in `.claude/launch.json`.

**Decisions:** none cross-cutting. Plan-gate choices in the work log: one encoded link parameter over a descriptor fetched by URL; a Playwright harness with the repository created at T1; the export fetched from the package's site rather than vendored. Implement gate: a link without `participant` makes the start screen ask; items numbered by form position as the printed shuffled form does.
