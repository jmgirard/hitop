# M091: The HiTOP-SR scoring functions score printed-order columns through a module's recorded item order

**Status:** done (2026-09-11, PR #99 https://github.com/jmgirard/hitop/pull/99)

**Goal:** `score_hitopsr()` and `reliability_hitopsr()` take a `layout` argument, and `layout = "printed"` scores columns collected in a shuffled form's printed order through the module's `item_order` attribute.

**Outcome:** Both functions gain `layout = c("instrument", "printed")` after `module`. It is resolved with `rlang::arg_match()`, so a bad value blames the exported function and names both values. `layout_items()` in `R/module.R` refuses a `"printed"` call with no module, a module with no `item_order`, or an `item_order` that is not a permutation of `module$items`. The refusals are unclassed `cli_assert()` aborts that name `layout` and hint at `randomize = TRUE` and `"instrument"`. The helper runs `validate_items()`, `validate_item_uniqueness()`, and `warn_item_order()` on the caller's own vector, then returns `items[match(module$items, item_order)]`. `prep_items()` gains `check_order`, threaded through `score_engine()` and `reliability_engine()`, so the permuted vector skips the ascending-name heuristic. The hand-reorder recipe left the roxygen of `generate_docx_hitopsr()`, `read_module()`, and `write_module()` and the modules article. Each names `layout = "printed"` instead. The `items` help says the name warning fires by design on printed-order names and that positions avoid it. `tests/testthat/test-layout.R` holds hand fixtures (HSR 310 reverse-keyed pair, unkeyed pair), a 3-cycle and a seeded shuffle on a four-scale module, the whole instrument, alpha and mocked-omega checks, the refusals, and warning counts. `data-raw/characterize_layout/` holds the AC1 characterization (251 of 251 recorded calls identical between merge base and branch). NEWS entry and a DESIGN.md scoring-paragraph clause.

**Decisions:** none cross-cutting. Plan-gate choices in the work log: an explicit argument over automatic detection from the attribute, an argument over a separate exported reorder helper, and unclassed refusals over a classed condition. The name is `layout` because `order` and `printed` collide with `omega` and `prefix` under partial matching.
